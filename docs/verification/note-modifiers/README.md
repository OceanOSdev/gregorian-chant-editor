`npm run build`, then start `npm run preview -- --host 127.0.0.1`. In separate
terminals start:

```bash
chromium --headless --no-sandbox --disable-gpu --remote-debugging-port=9230 --user-data-dir=/tmp/chant-8a-chromium about:blank
mkdir -p /tmp/chant-8a-firefox
firefox --headless --remote-debugging-port 9231 --profile /tmp/chant-8a-firefox about:blank
```

```bash
node docs/verification/note-modifiers/browser-check.mjs
CHANT_FIREFOX_URL=ws://127.0.0.1:9231/session node docs/verification/note-modifiers/browser-check.mjs
```

browser setup; set the same Firefox variable for BiDi. Restart Firefox after
each completed driver, which ends its owned session. Production assets are
checked under `http://127.0.0.1:4173/gregorian-chant-editor/`. Temporary screenshots

## Limits and deferred work

Automatic placement uses conservative occupied rectangles, including the whole
Porrectus ribbon; it can displace signs farther than optical contour-aware
engraving. The current compounds retain separate episema strokes instead of
risking ambiguous bridges. Manual orientation, authored joins/breaks, across-neume
joining, vertical episema/ictus and accidentals are deferred. No playback timing
is assigned. Signed neume ink expands the vertical canvas, but fixed lyric and
system spacing can still overlap extreme pitches; no vertical collision engine
or neume ledger lines were added. Responsive notation retains its existing small
target limitation. Hosted Pages deployment and owner visual acceptance remain
separate from local production verification.

## PR #64 review: stable modifier controls

The modifier fieldset now stays mounted above the score, with a fixed legend,
a separate target caption and compact wrapping controls. With no selected note,
the same controls are disabled and the caption says “Select a note to edit.”
This prevents selection from inserting/removing a panel or wrapping a variable
legend above the notation. Existing command, history, native select and focus
paths are unchanged; no engraving change is included.

The expanded production browser driver passed in Chromium and Firefox at 1440px
and 320px. It measures the score SVG's document position, width and height and
the first note target's document Y coordinate before and after native pointer
selection, switching through every constituent of all seven kinds, background
click deselection and Escape. Every measurement stays equal within 0.1 CSS px.
It also checks enabled/disabled controls, unchanged cache bytes and undo history,
and page containment. The existing modifier/file/history/keyboard cases run in
the same driver and still pass. Native focus scrolling is distinct from these
document-coordinate layout assertions.

Formatting, lint, all 67 test files / 1,343 tests, production build and diff
checks passed again. Agent-inspected comparison images show the same notation
position with [no selection](stable-unselected-firefox-320.png) and
[a selected note](stable-selected-firefox-320.png) in Firefox at 320px; desktop
Chromium and Firefox screenshots were inspected in the temporary output too.
Diagnostics: Chromium `/tmp/chant-note-modifiers-SS6iJl`, Firefox
`/tmp/chant-note-modifiers-F54nYR` (BiDi port 9243). Reproduce with the same driver
commands above, setting `CHANT_FIREFOX_URL` to the active disposable session.
Dense compound engraving remains an owner acceptance observation; this focused
follow-up changes only the control location and its browser regression checks.

## Porrectus mora refinement — owner-selected trailing placement

The [reference investigation and rendered comparison](porrectus-mora/README.md)
found that Gregorio deliberately uses trailing Porrectus dots, with ambiguous
overlap for equal outer pitches, and interprets double signs across the final
two notes. No conventional three-way local placement was established. The
owner subsequently chose conventional trailing placement. The focused refinement
uses compact clearance and the second note's adjacent-ascent line exception;
the accepted note-level model and v2 meaning are unchanged. The linked record
contains current behavior, limitations, before/after evidence and checks.
