# Stage 8A verification

Implementation follows [Accepted ADR 0017](../../adrs/0017-model-rhythmic-modifiers-on-notes.md)
and the [retained plan](../../plans/stage-8a-rhythmic-note-modifiers.md).
Owner PR acceptance and plan closeout remain pending; no merge was performed.
The owning guides describe the semantic, persistence, interaction and engraving
contracts. No new architectural decision was needed.

## Automated and rendered evidence

Local checks passed: `npm run format:check`, `npm run lint`, `npm test`
(67 files / 1,343 tests), `npm run build`, and `git diff --check`.
Node is v24.12.0 locally; `.nvmrc` declares v24.18.0. Hosted CI is separate.

Pure tests cover:

- One-note edits, coexistence/removal, invalid/no-op identity, structural sharing,
  stable IDs, movement, deletion/normalization and exact undo/redo snapshots.
- All seven kinds, individual and consecutive signs, line/space and boundary
  pitches, intervals 1/2/3/5/12, ink/staff clearance, unchanged head and anchor
  geometry, bounded horizontal growth, mixed events and multi-system wrapping.
- V2 semantic round trips and invalid zero/negative/extra/fractional/wrong-type
  fields; v1's exact note shape still rejects signs. Existing safe-integer,
  unknown-field, malformed-object, size and filename regressions remain gates.
- V1 cache hydration without writes, same-key upgrade on the next successful
  save, full IDs/lyrics/division/clef preservation and foreign/future cache guards.

The production repo-subpath editor passes both `browser-check.mjs` here and
`../local-persistence/browser-check.mjs` in headless Chromium/CDP and Firefox/BiDi.
The modifier driver checks:

- Actual baseline v1 files through both import and preexisting localStorage;
  unchanged bytes on hydration, no signs, semantic equality after v2 save.
- Native pointer selection, native SVG keyboard selection of every constituent
  of all seven kinds, simultaneous double mora/episema and accessible labels.
- Synchronous cache bytes in the same task as each React select change,
  immediate refresh recovery, native Tab between controls, retained select
  focus, native pitch arrows preserving marks, atomic Undo/Redo, file/Blob export
  and reimport with exact semantic equality.
- Individual ordinary single marks, dense compound marks, mixed divisions,
  authored clefs/custodes, continuation lyrics, system ends, actual SVG ink boxes
  inside the viewBox and responsive containment at 1440px and 320px.
- Invalid/foreign/future cache bytes protected through attempted edits.

The persistence regression separately checks corrupt-cache replacement, another
tab, unavailable/quota storage, cancellation, title drafts, pending lyric/clef
workflows, export filenames, malformed and oversized imports. Its fixture now
expects v2 writes. DOM change/File events and stubbed confirmation/download
handling are explicit test techniques, not native dropdown/picker/dialog checks.
Screenshots were inspected by the implementation agent; no independent human
engraving or spoken-accessibility signoff is implied.

## Baseline provenance

`baseline-v1.chant.json` freezes the actual sample from
`origin/master:src/editor/domain/example-document.ts` before Stage 8A, serialized
with the original v1 envelope. `baseline-events-v1.chant.json` adds a legal
Stage 7A authored F clef before a minor division at the Torculus boundary.
Neither fixture is regenerated by the v2 codec. Both remain portable import
fixtures and are consumed by pure tests and the real browser driver.

## Reproduce

Use disposable profiles: these drivers replace the named app cache. Build with
`npm run build`, then start `npm run preview -- --host 127.0.0.1`. In separate
terminals start:

```bash
chromium --headless --no-sandbox --disable-gpu --remote-debugging-port=9230 --user-data-dir=/tmp/chant-8a-chromium about:blank
mkdir -p /tmp/chant-8a-firefox
firefox --headless --remote-debugging-port 9231 --profile /tmp/chant-8a-firefox about:blank
```

Then run:

```bash
node docs/verification/note-modifiers/browser-check.mjs
CHANT_FIREFOX_URL=ws://127.0.0.1:9231/session node docs/verification/note-modifiers/browser-check.mjs
```

Run `node docs/verification/local-persistence/browser-check.mjs` with the same
browser setup; set the same Firefox variable for BiDi. Restart Firefox after
each completed driver, which ends its owned session. Production assets are
checked under `http://127.0.0.1:4173/gregorian-chant-editor/`. Temporary screenshots
are diagnostic outputs; retained review images below are not golden comparisons.

## Limits and deferred work

Automatic placement uses conservative occupied rectangles, including the whole
Porrectus ribbon; it can displace signs farther than optical contour-aware
engraving. The current compounds retain separate episema strokes instead of
risking ambiguous bridges. Manual orientation, authored joins/breaks, across-neume
joining, vertical episema/ictus and accidentals are deferred. No playback timing
is assigned. Signed neume ink expands the vertical canvas, but fixed lyric and
system spacing can still overlap extreme pitches; no vertical collision engine
or neume ledger lines were added. Responsive notation retains its existing small
target limitation. Hosted Pages deployment and owner visual acceptance remain
separate from local production verification.
